# Segurança

O kit roda dentro do Claude Code com as permissões da sua sessão. Os hooks em `hooks/` executam
scripts na sua máquina a cada escrita de arquivo. Leia-os antes de instalar.

Se encontrar um hook ou script que escreve fora do projeto, vaza conteúdo, executa código não
confiável ou contorna as permissões do Claude Code, **não abra issue pública**. Reporte de forma
privada pelo GitHub: **Security → Report a vulnerability** neste repositório.

*Found a security issue? Please report it privately via **Security → Report a vulnerability**.*

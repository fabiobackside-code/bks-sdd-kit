# C4 Model

Quatro niveis de zoom: Contexto, Container, Componente, Codigo. Cada nivel responde a uma
pergunta diferente, para um publico diferente.

## Quando e a escolha certa

- ha publicos distintos: executivo quer Contexto, desenvolvedor quer Componente
- o sistema tem fronteiras que precisam ficar explicitas
- a arquitetura vai ser explicada mais de uma vez, para gente diferente

## Os niveis

| Nivel | Responde | Para quem |
|---|---|---|
| 1 · Contexto | o sistema e quem fala com ele | qualquer um |
| 2 · Container | as pecas executaveis e como se falam | tecnico |
| 3 · Componente | o que ha dentro de um container | quem vai implementar |
| 4 · Codigo | classes e relacoes | raramente vale a pena |

O nivel 4 quase nunca compensa: envelhece a cada commit. Gere sob pedido explicito.

## Como aplicar a notacao

Renderiza em Mermaid. A paleta BKS mapeia nos elementos do C4:

| Elemento C4 | Cor BKS |
|---|---|
| sistema em foco | azul backend |
| sistema externo | cinza externo |
| banco de dados | verde storage |
| fila ou topico | laranja broker |
| pessoa ou canal | vermelho acesso |

Fronteira de sistema vira `subgraph`.

## Limite honesto

Um diagrama por nivel. Misturar niveis produz o diagrama que nao serve a ninguem — nem geral o
bastante para o executivo, nem detalhado o bastante para quem implementa.
